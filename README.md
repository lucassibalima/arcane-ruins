# 🎮 Arcane Ruins

Jogo desenvolvido utilizando **Construct 3** como parte da disciplina **Experiência Criativa: Explorando Computação e Inteligência Artificial** do curso de **Ciência da Computação da PUCPR**.

## 📖 Sobre o Jogo

**Arcane Ruins** é um jogo de aventura e exploração em que o jogador percorre ruínas misteriosas enfrentando desafios e obstáculos ao longo do caminho.

O projeto foi desenvolvido com o objetivo de aplicar conceitos de lógica de jogos, design de fases, interação com o usuário e desenvolvimento de aplicações interativas utilizando a plataforma Construct 3.

---

## 🎯 Objetivos do Projeto

* Desenvolver um jogo digital utilizando Construct 3.
* Aplicar conceitos de programação baseada em eventos.
* Criar mecânicas de movimentação e interação.
* Trabalhar elementos visuais e sonoros para melhorar a experiência do jogador.
* Desenvolver habilidades de planejamento e criação de jogos digitais.

---

## 🕹️ Funcionalidades

* Controle do personagem.
* Sistema de movimentação e exploração.
* Cenários temáticos inspirados em ruínas e aventuras.
* Efeitos sonoros e trilha sonora.
* Interface intuitiva para o jogador.
* Mecânicas de progressão dentro do jogo.

---

## 🛠️ Tecnologias Utilizadas

* Construct 3
* HTML5
* JavaScript (gerado pelo Construct)
* Recursos gráficos e sonoros
